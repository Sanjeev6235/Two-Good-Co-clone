A front-end website recreation inspired by Two Good Co., created to explore editorial layouts, product-focused presentation, typography, and interactive web design.

> This is an independent educational clone for front-end practice and is not affiliated with Two Good Co.

## Project Overview

The project recreates the look and feel of a modern brand website using core web technologies. The focus is on arranging content and visual assets into a clear, engaging page experience.

## Features & Focus Areas

- Structured landing page built with HTML
- Custom page layout and styling with CSS
- JavaScript for browser-side interactions
- Image assets organized in a dedicated folder
- Product and brand-inspired visual presentation
- Practice with spacing, typography, and responsive styling

## Built With

| Technology | Purpose |
| --- | --- |
| HTML5 | Page structure |
| CSS3 | Layout, typography, and visual styling |
| JavaScript | Interactive behavior |

## Getting Started

1. Clone the repository: `git clone https://github.com/Sanjeev6235/Two-Good-Co-clone.git`
2. Open the downloaded folder.
3. Launch `index.html` in any modern browser.

This is a static front-end project; no backend or package installation is required.

## Project Structure

- `index.html` — website markup
- `style.css` — styles and responsive layout
- `script.js` — JavaScript interactions
- `image/` — visual assets
